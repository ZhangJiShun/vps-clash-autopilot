# Trust report / 权限审查

版本 0.1.0，2026-10-28。Owner: Repository maintainers。Review cadence: monthly。

来源：本仓库新编写的实验性 Skill，暂无公开下载量或用户评价证据。辅助工具依赖仅 PyYAML、qrcode；通过独立 Python 环境安装，不修改全局环境。

已审阅 SKILL、辅助代码、测试、双语 README 与引用文档；独立代码审阅发现的两项问题已修复并加回归测试：拒绝未支持的 HY2 跳端口输入；HEAD 重定向不标记内容成功。

## 实际能力与风险

- 本地脚本可读取明确指定的 Clash 文件、写入私有候选/备份并应用授权计划，通过明确的本机 Unix socket 修改选择器，离线生成含认证信息的二维码。
- 网络探测只访问固定 Google、YouTube、ChatGPT HTTPS 端点；不上传配置、Cookie、备份或二维码。依赖安装访问包管理源，应先审阅依赖。
- 服务器改动由宿主 Agent 执行，包括证书、防火墙和可能的关机启动，属于高权限系统操作，整体按 HIGH/EXTREME 风险审查。没有实际目标和用户授权时不得执行。
- skill-vetter 对 root/security 配置类 Skill 的默认结论是“不安装”；因此本次没有全局安装，也没有绕过该规则。隔离目录解包和合成测试不激活后台、不修改真实系统。
- 安装不会增加电脑控制能力或权限。自然语言规则与 --approve 不能技术性强制宿主执行权限隔离。

## 检查结果与限制

源码允许清单与启发式隐私扫描由 scripts/release_check.py 执行；真实配置、截图、聊天、备份、密钥和生成式 reports 均不在公开清单。仅公开安装目标地址会包含 GitHub 账号标识。

Yao trust 静态扫描未发现密钥；其报告对网络检测能力有限（未识别全部 socket/curl 行为），以本节人工代码审阅为准。file_write reviewer approval 缺失；不得伪造审批。通用适配器权限元数据检查通过，但没有原生权限强制隔离证明。Yao 治理安装模拟未通过权限审批等门禁，不能称为正式受控安装通过。

首版不自动安装、无用户运行遥测、不读取 .env/SSH 私钥/浏览器 Cookie、不安装根证书、不执行下载的 shell 脚本。分享链接是认证材料，不要公开。发布前由用户审阅精确清单与限制。
